小程序开工包 v2.2
========================================

一句话：把它丢给你的 AI 编程工具，它会先采访你，再带你从想法做到提审。
免费开源（MIT），随便用、随便改。


三步用起来
----------------------------------------
1. 解压到一个空文件夹（别和别的东西混在一起）
   解压完会多出一层：小程序开工包-v2.2\

2. 用 AI 编程工具打开【里面那一层】，不是它的上一级
   判断标准：打开后第一眼能看到 AGENTS.md 这个文件
   选错层 = AI 看不见 AGENTS.md = 只会给你念目录

   WorkBuddy       打开工作区，选 小程序开工包-v2.2 这一层
   Cursor          File → Open Folder，同上
   Claude Code     终端 cd 进这一层，输入 claude
   网页版 AI       读不了本地文件。把 AGENTS.md 和
                  00-开工\PROGRESS.md 上传给它，再发第 3 步

3. 发这一句（能复制就复制，别自己改写）：
   读一下 AGENTS.md，带我做一个微信小程序，直接开始，别先给我讲目录。


怎么判断它真的接手了
----------------------------------------
第一段是【一个带选项的问题】→ 成了，跟着答就行
第一段是"我看到你有以下文件…"或列目录 → 没接手
   → 再发一遍上面那句；还不行用 03-提示词\一句话启动.md 第二句


然后它会干什么
----------------------------------------
问你 4 个带选项的问题（给谁用 / 解决什么 / 什么主体 / 你会不会写代码）
→ 给你判断（能不能做、最大风险、最小版本砍到几页）
→ 带你走 7 个阶段：合规、策略、设计、技术、开发、内容、提审

全程它会更新 00-开工\PROGRESS.md。
换会话、关电脑、隔一周回来，它读这个文件就知道做到哪了。


你要做什么
----------------------------------------
不是写代码，是做决定 + 验收：
· 回答它的选择题（不知道就选"我说不好"，它给默认方案）
· 在微信开发者工具或真机上点一遍
· 截图告诉它哪里不对


卡住了
----------------------------------------
· AI 开始念目录、不问你问题 → 看 03-提示词\一句话启动.md，用里面第二句
· 不知道做到哪了 → 打开 00-开工\PROGRESS.md
· 想重来 → 删掉 我的项目\ 和 00-开工\PROGRESS.md，重新发启动语
· 出新版了 → 新解压一个文件夹，只搬 我的项目\、miniprogram\、cloudfunctions\、PROGRESS.md
· 提审被拒 → 看 05-红线\审核红线.md 第六节，先分类再改


第一次用，记住三件事
----------------------------------------
1. 阶段 0（合规）不要跳。个人主体做不了 AI 生成、支付、直播、web-view，
   做到一半才发现，前面全白做。
2. 用真机验收，不要只看模拟器。
3. 它说"改完了"，你要问一句"我点哪里验收"。


目录是干什么的
----------------------------------------
AGENTS.md        AI 的开工说明，核心文件，别删
START-HERE.md    人看的说明（内容就是这份）
00-开工          阶段地图 + 进度状态机
01-阶段包        7 个阶段各自的操作手册
02-模板          8 份可填空的文档模板
03-提示词        10 组可复制的提示词
04-工具          check.js 体检脚本（node 04-工具\check.js ./miniprogram）
05-红线          技术红线 + 审核红线，写代码前必读
06-抖音投放      拍视频用的脚本和文案，用不上可以删
07-参与贡献      更新日志与发布说明
08-设计参考      设计 token / 配色 / 页面模式，阶段 2 必读
09-示例-喝水记录  能跑的三页示例，阶段 4 对照它


现在只要做一件事：发那句启动语，然后回答它的问题。
