# 配色方案

> 用户说不出想要什么颜色时，**别让他描述，直接报编号让他选**。
> 每套都给全了主色、底、文字、强调，抄进去就能跑。

---

## 怎么用

1. 报 3 套让用户选（不要给 10 套，选择过载）
2. 选中后把「主色 / 主色深 / 背景 / 强调」四个值替换进 `app.wxss`
3. 卡片永远 `#FFFFFF`，中性色永远用 `02-设计token.md` 里那套，**不要跟配色一起改**

**面积原则**：主色占全屏面积不超过 10%。
主色铺满整屏是新手最容易犯的错 —— 看起来像 2010 年的企业官网。主色只出现在：
主按钮、选中态、关键数字、图标点缀。

## 主色如何落到代码

主色只改四处，其余不动：

```css
/* 1. 主按钮 */
.btn-primary { background:#1677FF; }

/* 2. 选中态（tab、分段器、时段按钮） */
.tab.is-active { color:#1677FF; border-bottom:3rpx solid #1677FF; }

/* 3. 关键数字 */
.amount { color:#1677FF; font-size:52rpx; font-weight:700; }

/* 4. 浅底标签 */
.tag { background:#E8F1FF; color:#0E5FD8; }
```

配套的 `app.json` 也要改（否则导航栏还是默认色）：

```json
{
  "window": {
    "navigationBarBackgroundColor": "#FFFFFF",
    "navigationBarTextStyle": "black",
    "backgroundColor": "#F4F7FB"
  }
}
```

> `navigationBarTextStyle` 只有 `black` / `white` 两个值。
> 导航栏底色深就用 `white`，浅就用 `black`，没有第三种。

## 三个坑

1. **主色当背景用**：整屏 `#1677FF` 看着很「专业」，实际读两屏眼睛就累。深色背景只给顶部 280rpx 的个人中心头部。
2. **灰阶和彩色混着调**：改了主色却把 `#8A8A8A` 改成「和主色搭的蓝灰」，结果全站两种灰打架。中性色不动。
3. **功能色被主色带跑**：主色是橙，就把「危险」也做成深橙 —— 用户分不清删除和提交。危险永远是红 `#EE0A24`。
