# 组件配方

> 可以直接复制进项目的 WXML + WXSS。故意不引第三方库 —— 小程序引 UI 库会多 300KB 包体，
> 而且样式覆盖起来比手写更麻烦。
>
> 默认已经按 `02-设计token.md` 的数值写死；换配色时只改带 `★` 的几行。

---

```css

```

## 3. 按钮（主 / 次 / 加载 / 禁用）

```xml
<view class="btn btn--primary {{submitting ? 'is-disabled' : ''}}"
      hover-class="{{submitting ? '' : 'btn--active'}}"
      bindtap="onSubmit">
  <text wx:if="{{!submitting}}">提交预约</text>
  <view wx:else class="btn__loading">
    <view class="dot"></view><view class="dot"></view><view class="dot"></view>
  </view>
</view>
```

```css
.btn {
  height: 88rpx;
  border-radius: 16rpx;
  display: flex;
  align-items: center;
  justify-content: center;
  font-size: 32rpx;
  font-weight: 500;
}
.btn--primary { background: #07C160; color: #FFFFFF; }            /* ★ */
.btn--primary.btn--active { background: #06AD56; }                 /* ★ */
.btn--secondary {
  background: #FFFFFF;
  color: #07C160;                                                  /* ★ */
  border: 1rpx solid #07C160;
}
.is-disabled { background: #C8C8C8 !important; color: #FFFFFF !important; }

.btn__loading { display: flex; gap: 8rpx; }
.dot {
  width: 12rpx; height: 12rpx; border-radius: 999rpx;
  background: rgba(255,255,255,.9);
  animation: bounce 1s infinite;
}
.dot:nth-child(2) { animation-delay: .15s; }
.dot:nth-child(3) { animation-delay: .3s; }
@keyframes bounce {
  0%,80%,100% { transform: translateY(0); opacity:.5; }
  40%         { transform: translateY(-6rpx); opacity:1; }
}
```

> 用 `view` 而不是原生 `button`，省掉一堆默认样式覆盖。
> 需要分享/开放能力时才用 `button open-type`。

## 5. 价格

```xml
<view class="price">
  <text class="price__sym">¥</text>
  <text class="price__int">128</text>
  <text class="price__dec">.50</text>
</view>
```

```css
.price { display: flex; align-items: baseline; color: #1A1A1A; }
.price__sym { font-size: 24rpx; margin-right: 2rpx; }
.price__int { font-size: 52rpx; font-weight: 700; line-height: 1; letter-spacing: -1rpx; }
.price__dec { font-size: 28rpx; font-weight: 700; }
```

> 金额一律 `font-variant-numeric: tabular-nums`（等宽数字），
> 否则列表里上下两行的小数点对不齐。WXSS 支持这个属性。

## 10. 分段器（Tabs）

        class="tabs__item {{current === item.value ? 'is-active' : ''}}"

## 13. 半屏弹层

```xml
<view class="mask {{visible ? 'is-show' : ''}}" bindtap="close" />
<view class="sheet {{visible ? 'is-show' : ''}}">
  <view class="sheet__bar"></view>
  <view class="sheet__head">
    <text class="t-subtitle">选择时间</text>
    <text class="sheet__close" bindtap="close">✕</text>
  </view>
  <scroll-view scroll-y class="sheet__body"><slot /></scroll-view>
</view>
```

```css
.mask {
  position: fixed; inset: 0; background: rgba(0,0,0,.5);
  opacity: 0; visibility: hidden; transition: opacity .2s; z-index: 999;
}
.mask.is-show { opacity: 1; visibility: visible; }

.sheet {
  position: fixed; left: 0; right: 0; bottom: 0;
  background: #FFFFFF;
  border-radius: 24rpx 24rpx 0 0;
  padding-bottom: env(safe-area-inset-bottom);
  transform: translateY(100%);
  transition: transform .25s ease-out;
  z-index: 1000;
}
.sheet.is-show { transform: translateY(0); }
.sheet__bar { width: 64rpx; height: 8rpx; border-radius: 999rpx; background: #E5E5E5; margin: 16rpx auto; }
.sheet__head { display: flex; align-items: center; justify-content: space-between; padding: 8rpx 32rpx 24rpx; }
.sheet__body { max-height: 60vh; padding: 0 32rpx 32rpx; }
```

> `inset: 0` 在小程序里可用。若目标基础库很老，改成 `top:0;right:0;bottom:0;left:0;`。
