# 一句话启动

> 三条路各一句。AI 没自动开始，就先补这一句。
> 从短到长试，一般第一句就够。

---

## 路 1 · 发一个文件（`AGENT-开工.md`）

**第一句（99% 够用）**

```
读 AGENT-开工.md，带我做一个微信小程序，直接开始，别给我讲目录。
```

**第二句（它开始总结文件时用）**

```
停。不要总结文件内容。用带选项的问题采访我 4 个问题。现在就问。
```

**第三句（彻底不听话时用）**

```
你现在是我的小程序项目经理。规则：
1. 不要输出文件清单，不要问开放问题；
2. 一次问我一个带 3-4 个选项的选择题；
3. 问完 4 题，给我 8 行以内的判断，然后直接进入"合规确认"这一步。
开始问第一个问题。
```

读 AGENTS.md，带我做一个微信小程序，直接开始，别先给我讲目录。

## 换工具时的说法

| 工具 | 怎么发 |
|------|--------|
| **WorkBuddy** | 附件发 `AGENT-开工.md`；或用工作区打开能看见 `AGENTS.md` 的那一层 |
| **Claude Code** | `cd` 进那一层，输入 `claude`（会自动读 `CLAUDE.md`）；或直接把 `AGENT-开工.md` 内容粘进去 |
| **Codex / Cline / Aider** | 把工作目录设在能看见 `AGENTS.md` 的那一层；不能设目录就把 `AGENT-开工.md` 内容粘进第一条消息 |
| **Cursor** | 用 Cursor 打开那一层，`.cursor/rules` 自动生效；或粘 `AGENT-开工.md` |
| **豆包 / Kimi / 微信里的 AI** | 上传 `AGENT-开工.md`（传不了就把后缀改成 `.txt`），再说第一句 |
| **ChatGPT 网页版** | 同上，传文件或粘全文 |

> 网页版 AI 也能陪你把前面几步走完（合规、页面清单、设计规范都可以在对话里定），
> 到写代码那一步它会**一个文件一个文件贴给你**，你复制进开发者工具。
> 这就是 `AGENT-开工.md` 第 15 节写的「C 档交付格式」，不是它偷懒。

## 怎么确认它接手了

它第一段必须是**一个带选项的问题**。出现下面这些，说明没接手，补第二句：

- 「我看到你有以下文件……」
- 逐个解释每个目录是干什么的
- 直接开始写代码（没采访就动手，说明它没读阶段门禁）

反过来，一次抛出十几个开放问题，也说明没读 —— 规则里写了「一次不超过 3 个问题，且必须有选项」。

## 装成技能（真正的「一句话」）

不想每次都发文件，就装成技能。**双击根目录的 `安装技能.bat`**，它会把技能复制到：

- WorkBuddy：`~/.workbuddy/skills/wechat-miniprogram-builder/`
- Claude Code：`~/.claude/skills/wechat-miniprogram-builder/`（检测到才会装）

重启工具，新建一个空文件夹，说：

```
我要做一个微信小程序
```

**它自己会开始采访你。** 技能是自包含的：七阶段手册、设计数值、故障预案都在
`references/` 里，脱离这个包也能跑完整个流程。装完这个文件夹可以删。

### 手动装也一样

```
.workbuddy\skills\wechat-miniprogram-builder\
  → C:\Users\你的用户名\.workbuddy\skills\
```

复制完确认路径是这样，中间不能多一层：

```
~/.workbuddy/skills/wechat-miniprogram-builder/SKILL.md   ✅
~/.workbuddy/skills/wechat-miniprogram-builder/skills/wechat-miniprogram-builder/SKILL.md   ❌
```
