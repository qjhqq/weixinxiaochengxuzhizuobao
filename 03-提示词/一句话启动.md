# 一句话启动

> 如果 AI 没有自动开始（没读 `AGENTS.md`），复制下面任一句发给它。
> 从短到长试，一般第一句就够。

---

## 第一句（99% 情况够用）

```
读一下 AGENTS.md，然后按里面的要求带我做一个微信小程序，直接开始，别先给我讲目录。
```

## 第二句（它还在给你做总结时用）

```
停。不要总结文件内容。读 AGENTS.md 和 00-开工/PROGRESS.md，
然后第一件事是用带选项的问题采访我 4 个问题。现在就问。
```

## 第三句（彻底不听话时用）

```
你现在是我的小程序项目经理。规则：
1. 不要输出文件清单，不要问我开放问题；
2. 一次问我一个带 3-4 个选项的选择题；
3. 问完 4 题，给我 8 行以内的判断，然后直接进入"合规确认"这一步。
开始问第一个问题。
```

## 换工具时的说法

| 工具 | 怎么说 |
|------|--------|
| WorkBuddy | 打开工作区 → 选**解压后里面那一层**（能看到 `AGENTS.md` 的那层），说第一句 |
| Claude Code | `cd` 进那一层，输入 `claude`，它会自动读 `CLAUDE.md` |
| Cursor | 用 Cursor 打开那一层，`.cursor/rules` 会自动生效 |
| ChatGPT / 网页版 | 没法读本地文件，用它自带的文件上传，把 `AGENTS.md` 和 `00-开工/PROGRESS.md` 传上去，再说第一句 |
| 豆包 / Kimi | 同上，先传 `AGENTS.md` |

> 只把 zip 拖进对话框不算「打开文件夹」：它能读文档、能陪你聊，
> 但写不了 `我的项目/`，也跑不了 `check.js`。要真做出小程序，必须解压成文件夹。

---

## 怎么确认它接手了

它第一段必须是**一个带选项的问题**。出现下面这些，说明没接手，加发第二句：

- 「我看到你有以下文件……」
- 逐个解释每个目录是干什么的
- 直接开始写代码（没采访就动手，说明它没读阶段门禁）

反过来，如果它一次抛出十几个开放问题，也说明没读 AGENTS.md —— 那里写了「一次不超过 3 个问题，且必须有选项」。

## 装成长期技能（可选，最省事）

把 `.workbuddy/skills/wechat-miniprogram-builder` 整个文件夹复制到：

- WorkBuddy：`~/.workbuddy/skills/`
- Claude Code：`~/.claude/skills/`

之后不用每次丢包，直接说「我要做个小程序」，它就会带着这套流程接手。
