# 提示词模板库

> 用法：整段复制，把【】换成你的项目信息。前提是 AI 已经读过 `AGENTS.md`。
> 10 组，按开发顺序排。不用全用，缺什么抄哪段。

---

## 1. 一句话启动（每次新会话第一句）

```
请读项目根目录的 AGENTS.md 和 00-开工/PROGRESS.md，然后直接按你的判断继续推进，
不用问我"要不要开始"。
```

## 2. 首轮立项（AI 没主动采访你时，用这段踢它一脚）

```
我要做一个微信小程序，但我现在只有一个模糊想法。
请你：
1. 一次问我 4 个带选项的封闭问题（谁用 / 解决什么 / 主体 / 我技术到什么程度）；
2. 问完后给我 8 行以内的判断：能不能做、最大风险、最小版本砍到什么样；
3. 直接带我从阶段 0 开始，不要等我说"开始"。
不要先给我讲小程序是什么，不要输出文件目录。
```

## 3. 合规体检（阶段 0）

```
我的情况：
- 主体：【个人 / 个体户 / 公司】
- 想做的功能：【列出 5-8 个】
- 目标用户：【谁】
请逐条判断：✅ 能做 / ⚠️ 要绕 / ❌ 不能做，并给每个 ⚠️ 一个合规替换方案，
说清替换后用户体验损失在哪。涉及类目和资质的，标明"需你到官方类目表核对"。
最后输出成表格，我要直接存成能力清单。
```

## 4. 砍 MVP（阶段 1，最有用的一段）

```
这是我的功能清单：【贴清单】。
请按这四条逐条判断，任何一条命中就砍：
1. 没有它用户还能完成核心动作吗？
2. 它需要新资质或新类目吗？
3. 它需要用户之间互动吗？
4. 它能让用户"今天就看到东西"吗？
砍到 8 个页面以内。每个被砍的功能写一句"什么条件下可以加回来"。
不要安慰我，该砍就砍。
```

## 5. 视觉重做（阶段 2，附图）

```
这是【App 名】的截图（附件）。请把【页面名】按这个风格重做：
- 只改视觉，保留现有功能、信息层级、交互；
- 先定设计 token（主色/圆角/阴影/字号）写进 app.wxss，再改页面；
- 改完告诉我改了哪些 class，我要截图对照。
注意：WXSS 不支持 CSS 变量，全部写字面值。
```

## 6. UI 验收迭代（截图反馈，最高频）

```
（附图）这个页面有 3 个问题：①【】②【】③【】。
请先给根因分析，再给修复方案，最后直接改代码。
改完跑一遍 check.js，把结果一并汇报，并告诉我"我要点哪里验收"。
```

## 7. 修 Bug（根因优先）

```
现象：【具体现象，附截图最佳】
已确认：【我试过的操作 / 已排除的可能】
要求：
1. 先给 3 个最可能的根因，以及怎么验证（我点哪里能区分是哪一个）；
2. 我确认后你再改；
3. 禁止"加个 try-catch 让它不报错"这种治标方案，除非你先说明代价。
```

## 8. 云函数 / 外部能力

```
我要在云函数里实现【功能，如：调第三方 OCR 识别图片文字】。
要求：
- 密钥从环境变量读取，代码里只允许 `process.env.XXX || ''`；
- 超时调到 20 秒以上（默认 3 秒不够），并在 config.json 里写好；
- action 走统一入口路由，不新建独立云函数；
- 给出前端 wx.cloud.callFunction 的封装代码，含统一错误处理；
- 告诉我部署时选"云端安装依赖"还是"所有文件"，以及怎么验证通了。
```

## 9. 合规版「智能问答」（个人主体绕类目）

```
我想做"智能问答"，但个人主体过不了生成式 AI 类目。
请设计「预置内容库 + 检索式问答」方案：
1. 内容库字段设计（要支持标签、关键词、相似问题）；
2. 匹配算法：关键词命中 + 标题加权 + 标签加权，阈值怎么定；
3. 匹配不到时的兜底话术（要显得专业，不能像坏了）；
4. 前端对话页 UI 要点（气泡、加载态、免责声明位置）；
5. 怎么让它看起来"像懂我"，而不是一个搜索框。
```

## 10. 提审前体检

```
我要提审了。请按 02-模板/提审自检表.md 逐项检查我的项目：
- 我的是【主体类型】+【类目】，重点核查能力边界；
- 通读隐私政策页，指出审核员可能挑刺的表述；
- 全项目搜索：web-view、硬编码密钥、var( 、>200KB 图片、违禁词，逐项报告；
- 输出一份"必须改 / 建议改 / 可以不管"三档清单。
```

---

## 使用纪律

1. **一次一个目标**：别在一条消息里塞「改 UI + 修 bug + 加功能」
2. **截图 > 文字**：UI 问题一律截图，指哪打哪
3. **改完必跑校验**：把「跑 check.js」变成口头禅
4. **密钥不进对话**：别把真 Key 粘进聊天窗口
5. **AI 生图先确认**：生成图先看预览，满意了再让它接入项目
6. **说「不对」的时候给证据**：截图、报错原文、你点了什么。只说"感觉不对"AI 只能瞎猜
