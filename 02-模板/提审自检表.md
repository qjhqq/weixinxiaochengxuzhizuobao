# 提审自检表

> 每一项都要在**真机**上实际点过再勾。个人主体重点看前两节。

## 一、主体与类目

- [ ] 主体类型与所选类目匹配
- [ ] 类目没有命中个人主体不开放的范围（生成式 AI / 支付 / 直播）
- [ ] 名称、简介、功能描述与实际功能一致，无擦边表述
- [ ] 简介里没有「AI 智能」「最」「第一」「国家级」等词
- [ ] 个体户/公司：营业执照经营范围覆盖所选类目

## 二、隐私与合规

- [ ] 隐私政策页可访问（不登录也能打开）
- [ ] 内容含：收集范围 / 使用目的 / 存储方式 / 共享情况 / 用户权利 / 联系方式
- [ ] 首次进入有隐私弹窗，「同意」「不同意」都可用
- [ ] 同意状态已落盘，再次进入不重复弹
- [ ] 有撤回同意的路径
- [ ] 涉及未成年人/健康数据：有单独章节 + 页面内显眼说明
- [ ] 全站无 web-view、无外部跳转
- [ ] 无诱导分享（分享得奖励、强制转发）
- [ ] 无虚拟支付 / 会员付费
- [ ] 所有算法、AI、健康类输出都有「仅供参考，不构成诊断/专业建议」
- [ ] 订阅消息是用户主动点击触发，无诱导

## 三、功能与质量

- [ ] 核心链路走通：进入 → 核心动作 → 数据落库 → 能看到结果
- [ ] 每个页面真机点过一遍
- [ ] 上传类功能有双入口（拍照 / 从相册选择）
- [ ] 用户拒绝授权后，有引导去设置的文案
- [ ] 空态 / 加载态 / 失败态 三态齐全
- [ ] 断网时有提示，不是白屏

## 四、资源与性能

- [ ] 无 >200KB 图片警告
- [ ] 主包 < 2MB
- [ ] 控制台无红色报错
- [ ] 无未处理的 Promise rejection
- [ ] 首屏加载 < 3 秒（真机 4G 环境）

## 五、代码卫生

- [ ] 全项目搜索 `var(` → 0 结果
- [ ] 全项目搜索 `web-view` → 0 结果
- [ ] 全项目搜索 `AKID` / `sk-` / `api_key` / `secret` → 无真实密钥
- [ ] 无遗留的 `console.log` 打印敏感数据
- [ ] 无写死的测试数据

## 六、提交材料

- [ ] 功能页面填了 3-5 个核心页面，每个配**真机截图**
- [ ] 需登录才可用的，提供了可用的测试账号
- [ ] 补充说明写清「给谁做什么」，一句话
- [ ] 已跑 `04-工具/check.js`，0 红线
