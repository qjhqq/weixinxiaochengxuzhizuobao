## 云函数 action 清单

| action | 入参 | 返回 | 说明 | 超时 |
|--------|------|------|------|------|
| `addXxx` | | | | 3s |
| `listXxx` | `{ page, size }` | `{ list, total }` | | 3s |
| `getXxx` | `{ id }` | | | 3s |
| `removeXxx` | `{ id }` | | 软删除 | 3s |
| `initCollections` | `{}` | | 幂等建集合 | 20s |

> 涉及外部 API（OCR、大模型）的 action，超时统一调到 **20 秒以上**。

---

## 三条铁律

1. **时间存时间戳**，不存 `"2026-10-30"` 这种字符串
2. **权限默认「仅创建者可读写」**，要公开的单独放开
3. **软删除**（`deleted: true`），不真删
