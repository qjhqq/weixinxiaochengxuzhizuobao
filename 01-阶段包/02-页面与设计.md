# 阶段 2 · 页面清单与设计系统

> **这一步的目的**：让 UI 在你写代码之前就定死。风格返工的成本是逻辑返工的 3 倍。

---

## 先给结论

**不要用文字描述你想要什么风格。** 截 3-5 张你喜欢的大厂小程序页面，丢给 AI 说「按这个做」，比写 500 字描述高效十倍。

**设计 token 先定死**：主色、圆角、阴影、字号。写进 `app.wxss` 一次，后面所有页面只引用。

---

## AI 要做的事

### 1. 出页面清单（带入口出口）

不要只列页面名，要列**每个页面从哪来、到哪去、用户在这里做什么**：

| # | 页面 | 从哪进 | 主要动作 | 去哪 | 空态 |
|---|------|--------|---------|------|------|
| 1 | 首页 | 启动 | 看概览 / 进核心功能 | 记录页 | 有引导 |
| 2 | 记录页 | 首页 | 填一次数据 | 详情页 | — |
| 3 | 详情页 | 列表 | 看趋势 / 改 / 删 | 返回 | 有 |
| 4 | 我的 | tabBar | 设置 / 隐私政策 | — | — |
| 5 | 隐私政策 | 我的 / 首启弹窗 | 阅读并同意 | 返回 | — |

**必须齐全的三类页面**（缺了提审会被挑）：
- 隐私政策页（可访问、有同意按钮）
- 空态页（没数据时看到什么）
- 失败态（网络错、权限拒绝时看到什么）

### 2. 定设计 token

先问三个问题（一次问完，给选项）：

```
1. 你想要什么调性？ A 专业冷静（蓝/灰） B 温暖亲和（暖橙/米白） C 年轻活泼（高饱和撞色）
2. 主要用户年龄段？ A 学生 B 25-40 C 40+
3. 有没有你喜欢的 App 可以截图给我？（1-3 张，截图最准）
```

然后产出 token 表：

```
主色      #______   （按钮、强调、图标选中）
背景      #______   （页面底色，不要纯白）
卡片      #FFFFFF
主文字    #______   （不要纯黑，用 #1A1A1A）
次文字    #______   （#8A8A8A 左右）
分割线    #______
圆角      大 24rpx / 中 16rpx / 小 8rpx
阴影      0 4rpx 16rpx rgba(0,0,0,0.06)
字号      标题 36rpx / 正文 28rpx / 辅助 24rpx
行高      1.6
```

**写进 `app.wxss` 的方式**：小程序 WXSS **不支持 CSS 变量**，所以 token 必须以注释 + 字面值的形式落地：

```css
/* ===== 设计 token（改动只改这里，然后全局替换） =====
   主色 #2B6DE5 / 背景 #F5F7FA / 主文字 #1A1A1A / 次文字 #8A8A8A
   圆角 24/16/8rpx / 阴影 0 4rpx 16rpx rgba(0,0,0,.06)
   注意：WXSS 不支持 var()，全部写字面值
*/
```

### 3. 处理参考截图

用户给截图后，按这个顺序做：
1. 先说「我看到的 3 个特征」让他确认（例如：大标题 + 卡片圆角 24rpx + 底部悬浮按钮），不要直接开写
2. 只改**视觉**，不动信息层级和交互
3. 改完列出「改了哪些 class」，方便他截图对照

### 4. AI 生图纪律（重要）

- 生成的图**必须先发给用户看**，他说行才接入项目
- 含文字、字母、精确图形的画面（视力表、刻度、图表）**AI 必错**，改用代码绘制（Canvas 或 Python Pillow 按坐标画）
- 单图控制在 **200KB 以下**，PNG 照片转 JPEG（质量 85）通常省 70%
- **换图必须换文件名**：微信开发者工具对同名图片缓存极顽固，同名替换它显示旧图

## 常见坑

- **先写代码再想样式** —— 改一次全局样式要动十几个页面，改到第三次你会想重写。
- **主色选了高饱和色但全是文字** —— 高饱和只适合做点缀和小面积按钮，大面积用会廉价。
- **`navigationStyle: custom` 用了但没算状态栏高度** —— 顶部内容被刘海挡住，真机一看就废。
- **全局 `.page` 类被所有页面复用** —— 如果它带负边距（沉浸式头部专用），非沉浸式页面会被导航栏遮住，详见 `05-红线/技术红线.md`。
- **自定义 tabBar 不同步选中态** —— 每个 tab 页的 `onShow` 里都要手动 set，别指望它自己记住。
