# 小程序开工包 v2.1

**把一整套「一个人 + AI 做微信小程序」的流程，打包成一个压缩包。**
丢给你的 AI 编程工具，它会先采访你，再一步一步带你从想法做到提审。

> 不是提示词合集，是一套**带状态、带门禁、带产出物**的流程。
> 免费开源，MIT 协议，随便用、随便改。

---

## 它解决什么问题

独立开发小程序，卡住人的从来不是「不会写代码」，是这三件事：

1. **不知道今天该干什么** —— 功能想到哪做到哪，做了两周发现方向不对
2. **在错误的顺序上努力** —— 先写代码，最后才发现个人主体过不了这个类目
3. **AI 每次都要重新交代背景** —— 换个会话，它就不记得你是谁、做到哪了

这个包用三个机制解决：**阶段门禁**（做完一步才走下一步）、**产出物落文件**（不是聊完就没了）、**进度状态机**（AI 每次打开都知道做到哪了）。

## 三步用起来

```bash
# 1. 解压到一个空文件夹
# 2. 用 AI 编程工具打开这个文件夹（WorkBuddy / Cursor / Claude Code 都行）
# 3. 说这一句
```

```
读一下 AGENTS.md，带我做一个微信小程序，直接开始。
```

然后它会问你 4 个带选项的问题（给谁用 / 解决什么 / 什么主体 / 你会不会写代码），
问完给你判断，然后直接进第一个阶段。**你不需要再想下一步干什么。**

> AI 没自动开始？看 [`03-提示词/一句话启动.md`](03-提示词/一句话启动.md)，里面有更硬的句式。

## 七个阶段

| 阶段 | 干什么 | 产出物 | 不过门的后果 |
|------|--------|--------|------------|
| 0 合规 | 确认你的主体能做什么 | 能力清单 | 做完了上不了架 |
| 1 策略 | 北极星指标 + 砍到最小 | 产品策略 | 功能越做越多，永远上不了线 |
| 2 设计 | 页面清单 + 设计 token | 页面清单、设计规范 | 样式返工三遍 |
| 3 技术 | 技术栈 + 数据模型 | 数据模型 | 表设计错了，数据要重录 |
| 4 开发 | 一页一页做，每轮校验 | 能跑的小程序 | —— |
| 5 内容 | 首批内容库（与 4 并行） | 内容库 | 上线是空壳 |
| 6 提审 | 自检 → 提审 → 改 → 再提 | 提审记录 | 反复被拒，浪费一周 |

### 体检脚本

```bash
node 04-工具/check.js ./miniprogram
```

查十几类问题，其中 5 类是「提审前必须清零」的硬伤：

```
×  [wxss-no-css-var]     WXSS 不支持 CSS 变量，var(--x) 会让整页样式失效
×  [page-class-misuse]   非沉浸式页面用了带负边距的 .page 类，内容被导航栏挡住
×  [no-web-view]         个人主体用 web-view 必被拒
×  [hardcoded-secret]    密钥硬编码，分享即泄露
×  [page-missing]        app.json 注册了页面但文件不存在
```

改完再跑一次，退出码 0 才算过。可以挂 CI。

## 适合谁

- 想做第一个小程序，但不知道从哪下手的人
- 已经在做，但改来改去上不了线的人
- 会写代码但不懂审核规则的人
- 想拍「AI 编程」内容，需要一个真实素材的人

**不适合**：想找现成源码的人（这里只有方法论和模板，没有业务代码）。

## 常见问题

**完全不会写代码能用吗？**
能。所有技术决定由 AI 替你做，你负责验收——就是能看出「这里不对」。但你要有耐心，一个能过审的小程序，一个人做 2-4 周是正常的。

**支持 uni-app / Taro 吗？**
默认是原生 + 微信云开发（一个人做项目，运维成本比开发成本更贵）。会前端的话阶段 3 有换框架的说明。

**AI 不会自动读文件怎么办？**
不同工具行为不同。WorkBuddy / Claude Code / Cursor 会自动读 `AGENTS.md`，网页版 ChatGPT 需要你手动上传。见 `03-提示词/一句话启动.md`。

**这些审核规则是最新的吗？**
平台规则会变。包里给的是**判断框架和常见拒因**，具体类目和资质请在提审前核对微信官方文档。`05-红线/审核红线.md` 开头写了这条。

**能商用吗？**
MIT 协议，可以。但你做出来的小程序出了事，责任是你的，不是这个包的。
