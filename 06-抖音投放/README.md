# 抖音投放素材（可选）

> **这一整个目录都可以删。** 删掉不影响开工包的任何功能。

里面是给拍视频的人用的：

| 文件 | 用途 |
|---|---|
| `口播脚本.md` | 60s / 30s / 15s 三个时长，带时间轴 |
| `文案与封面.md` | 标题、封面文案、置顶评论、评论区应答 |
| `封面/` | 四张 1080×1440 成品图 + 可改字的 HTML 源文件 |

## 为什么单独放一层

封面四张加起来 700 多 KB，对只想做小程序的人是纯噪音。
但删了又可惜 —— 拿到这个包的人多半也想拍一条。

## 改封面

`封面/封面X-源文件.html` 是纯 HTML，改文字后重新截图即可：

```bash
# 需要 Edge 或 Chrome
msedge --headless --window-size=1080,1440 --screenshot=封面A.png 封面A-源文件.html
```

字体用的是系统自带的思源黑体 / 苹方，Windows 上会回退到微软雅黑，视觉上差一点但不影响。

## 一条原则

**第一条视频不要挂转化钩子。** 先讲「为什么卡住」，让人觉得你懂他；
第二条再给包。上来就喊「免费领取」的，完播率通常很难看。
